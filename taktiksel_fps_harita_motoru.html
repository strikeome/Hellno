Haritayı Kendi FPS Oyununa Nasıl Eklersin?

Bu harita tamamen bağımsız TacticalMapBuilder ve ProceduralTextureEngine sınıflarıyla kodlanmıştır. Hiçbir harici resim dosyasına ihtiyaç duymaz ve tüm duvarların çarpışma kutularını (map.colliders) otomatik üretir. 

// 1. Sahnenize Haritayı Tek Satırda Kurun:
const mapBuilder = new TacticalMapBuilder(scene);
const mapData = mapBuilder.buildFullCompetitiveMap();

// 2. Fizik / Çarpışma (AABB) ve Raycast Mermi Testi:
const wallColliders = mapData.colliders; // Tüm duvar, kutu ve rampa AABB'leri
const shootableMeshes = mapData.meshes;  // Mermi izi (Decal) bırakılabilir yüzeyler
const spawnPoints = mapData.spawns;      // { attackers, defenders, siteA, siteB, mid }

// 3. Işıklandırma Modunu Değiştirin ('sunset' | 'day' | 'cyber'):
mapBuilder.setAtmosphere('sunset');
